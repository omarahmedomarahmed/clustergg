How to read the verdict column

Anyone treating the Listed rows as a certificate of working software would be repeating the mistake this document exists to correct.

1 · The gamer the only user type that can be under 18

Signs up with a password, links a game account, and earns points and trophies. Everything a gamer can do is gated on one derived value, unlockState, which has three steps and no partial credit.

The capacity model is wrong twice over. The source of truth says "six games is six sponsors"; finance() returns 18, because its games figure is the post-raise target and nothing reconciles the two. And the rule itself is dead — the cap is per brand, so four brands may each buy a League challenge in one week. lib/dataroom/defaults.ts argues the round buys capacity by taking twelve more games live; that argument does not survive the correction, and tests/db/split.mts holds nine assertions enforcing it.
